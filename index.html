Comment transmettre le score et les réponses ?

À la fin du jeu, ajoute cette instruction dans son JavaScript. Les compétences sont facultatives (0 à 100) et « answers » peut contenir les réponses détaillées (JSON).

parent.postMessage({
  type: "chronoquest-result",
  score: 16,
  maxScore: 20,
  competencies: {
    C1: 80,
    C2: 75,
    C3: 90,
    C4: 85
  },
  answers: [
    { question: "q1", answer: "Réponse de l’élève" }
  ]
}, "*");
